# Telegram game bot project

## Что сделано
- код разложен по отдельным файлам запуска и поддержки;
- добавлена общая очередь отправки сообщений по чату, чтобы уведомления шли последовательно;
- исправлен потерянный callback для выбора чата из списка;
- сохранена исходная логика игр и настроек.

## Структура
- `main.py` — точка входа;
- `bot_legacy.py` — основная логика бота;
- `queueing.py` — очередь отправки сообщений;
- `fixes.py` — доп. обработчики и исправления.

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Задайте переменные окружения:
   - `BOT_TOKEN`
   - `MAIN_ADMIN_ID`
3. Запустите:
   ```bash
   python main.py
   ```

## Примечание
Если нужен ещё более глубокий рефакторинг на отдельные модули (`models`, `keyboards`, `services`), это можно сделать следующим шагом без изменения логики.
