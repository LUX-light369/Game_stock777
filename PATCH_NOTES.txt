# Изменения логики диктовки

Исправлена логика завершения диктовки:

## Было
После окончания списка:
- статус мог сбрасываться некорректно;
- ручная проверка и автопроверка могли прекращаться;
- диктовка считалась завершённой полностью.

## Стало
После окончания элементов:
- статус автоматически переводится в `paused`;
- индекс сохраняется на последнем элементе;
- ручная проверка и автопроверка продолжают работать;
- финалисты продолжают набираться;
- диктовка НЕ считается остановленной;
- только админ вручную завершает игру через кнопку `/stop`.

## Что изменить в dictation_loop

Заменить блок:

    settings.status = "paused"
    settings.index = 0

на:

    settings.status = "paused"

И НЕ сбрасывать index до команды stop.

Сброс index теперь должен происходить только в:
- menu_stop
- новом запуске игры (не resume)

## Дополнительно
Проверка победителей должна работать даже при статусе paused.
Проверка должна ориентироваться на:
- наличие активной игры;
- наличие финалистов меньше лимита;
- а не только на status == "playing".
